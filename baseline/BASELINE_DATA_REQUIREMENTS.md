# Baseline Data Requirements

Wave 1 must establish what can actually be measured before performance claims are authorized.

Required discovery domains:

- identifiable inquiries/leads and stage history where available;
- qualification/application/enrollment/start definitions and timestamps;
- ownership, next action, next-action date, blocked reason where available;
- original/latest source and campaign/channel attribution where available;
- student start, active, withdrawal, completion data definitions;
- graduate outcome goal and meaningful outcome stages;
- feedback/review/testimonial/referral activity and eligibility;
- partner/channel identity and contribution;
- capacity/economics only where authoritative.

For each field/metric capture logical definition, physical source system, physical field/report if verified, date coverage, completeness, known quality limits, owner, and confidence. Unknowns remain `UNKNOWN — BASELINE REQUIRED`.
