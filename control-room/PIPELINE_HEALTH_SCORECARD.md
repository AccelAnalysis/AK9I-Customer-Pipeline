# Pipeline Health Scorecard — Measurement Framework

No bootstrap values or targets are invented. Every current baseline and target below is `UNKNOWN — BASELINE REQUIRED` until authoritative evidence/executive decisions exist.

For every metric record: **Definition; Numerator; Denominator; Source system; Owner; Cadence; Current baseline; Target; Confidence.**

## Demand

Inquiries; qualified inquiries; source mix; campaign/channel contribution; acquisition cost when authoritative.

## Responsiveness

Time to first response; unassigned actionable records; overdue next actions; follow-up completion.

## Conversion

Inquiry→qualified; qualified→application; application→enrollment; enrollment→confirmed start; confirmed start→actual start.

## Student success

Starts; active students; retention; withdrawals; completions; satisfaction.

## Outcomes

Graduates with documented outcome goal; employer connections; interviews; offers; accepted outcomes; verified outcomes; time to outcome.

## Advocacy

Feedback rate; NPS or approved satisfaction measure; review request; review completion; testimonial rate; referral ask; referral generation.

## Capacity/economics

Where authoritative: seats/capacity; utilization; program mix; pipeline-to-capacity alignment; acquisition economics.
